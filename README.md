# Ani Player

Leanback anime catalog and media player client for Android TV, Fire TV, and Android mobile devices.

### Features
- 10-foot television interface for Android TV & Firestick
- Airing schedule tracker and catalog browser
- Adaptive 360p to 1080p video player
- 100% ad-free
